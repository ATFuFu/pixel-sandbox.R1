# 像素沙盒 PIXEL SANDBOX（网页版）

一个可以双击直接玩、也能放在静态服务器上的 2D 像素沙盒。

- 单文件 `index.html`，CSS 与 JavaScript 全部内联
- 纯 HTML5 Canvas 2D + 原生 JavaScript
- 无 CDN、无外部字体、无图片文件、无网络请求、无构建步骤
- 兼容 `file://`，不使用 ES Module、fetch、XMLHttpRequest 或 Web Worker
- 画布内部分辨率固定 1280×720，CSS 等比缩放，不拉伸
- 设置、存档使用 localStorage，不写文件系统

---

## 立即打开（本机链接）

当前开发环境已经在本机 `8000` 端口启动了静态服务，可以直接打开：

**http://127.0.0.1:8000/**

这个链接只在本机的静态服务器运行期间有效。如果关闭了终端或重启电脑，在本目录重新执行下面任意一种启动方式即可。若要把链接发给其他设备或公网，需要使用第四节的静态托管。

## 一、三种打开方式

### 1. 本地双击（file://）

直接双击 `index.html`，浏览器会以本地文件方式打开，不需要联网，也不需要启动服务器。

建议使用最新版 Edge、Chrome 或 Safari。游戏内的键盘快捷键需要页面获得焦点，点击一下画布即可。

### 2. 本地静态服务器

在本目录打开终端：

```powershell
cd pixel-sandbox-web
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

如果系统里没有 `python` 命令，可以换成 `py -m http.server 8000`，或者任何静态文件服务器。不要用 `file://` 拼服务器地址，直接访问上面的 `http://` 地址即可。

### 3. GitHub Pages

1. 新建一个 GitHub 仓库，把 `index.html`（和本 README）放到仓库根目录。
2. 提交并推送到 GitHub。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 里选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
5. 等几十秒，访问 `https://你的用户名.github.io/仓库名/`。

Netlify、Vercel、Cloudflare Pages 也可以：把整个 `pixel-sandbox-web` 目录拖进去，或把仓库导入后使用“静态站点 / 无构建”的默认配置，入口文件保持 `index.html`。

> 注意：`file://` 和 `http://` 两种打开方式的游戏逻辑完全一致，但浏览器会按“源”隔离 localStorage。  
> 从本地文件切到网址访问时，原来的存档不会自动跟过去；需要先在游戏里点「导出」，在新地址点「导入」。

## 三、烟测（自测）

在网址后加上：

```text
?selftest=1
```

例如：

```text
http://localhost:8000/?selftest=1
```

本地文件也可以手动输入带参数的地址，例如：

```text
file:///C:/你的路径/pixel-sandbox-web/index.html?selftest=1
```

页面加载后会自动执行物品、能力、物理、刚体、地形工具、Base64 存读档、整合物体序列化和 120 帧模拟测试，结果显示在页面上的可滚动面板里，同时输出到浏览器控制台。测试使用隔离地图，不会覆盖已有存档或当前世界。

自测覆盖项：

- 17 种物品全部可在光标位置放置
- 木板、三件家具、木棍、木箱、路灯作为整合刚体存在
- 整合物体单次放置、下落、翻滚、没有散成格子
- 旋转、三个地形工具
- 9 种能力全部成功释放
- 悬空方块逐格下落
- 树木失稳后转成刚体碎块
- 刚体下落 / 旋转 / 堆叠
- 大块悬空体素材料自动刚体化
- 地图 + 整合物体的双键存读档与扩展 `.bin` 容器
- 固定 30 Hz 模拟 120 帧
- Pointer Events 基础设施与面板开合
- 旋转按钮与右侧能力栏不重叠

## 四、游戏结构

### 物品栏（17）

体素材料：木块、土块、石块、铁块、铜块、泥块、雪块、沙子、岩浆、火药。

整合物体：木板、椅子、桌子、长凳、木棍、木箱、路灯。

- 一屏显示 10 个，可滚轮或箭头翻页
- 木板的长度随笔刷变化
- 所有整合物体都是一次点击放一个，按住不会连发
- 木板 / 家具 / 木棍 / 木箱 / 路灯会作为一个整体下落、碰撞、翻滚和堆叠，不会散成单个格子
- 体素材料仍按格子下落和反应；一次成形且悬空的石 / 木 / 金属材料达到 16 格时，会临时转成刚体以便翻滚，停稳后再烘焙回格子（这就是放置大块后“先像刚体、过一会又变回体素”的原因）
- 整合物体一次点击放一个；连续生成整合块时有约 300ms 的间隔，避免一长按或连续拖动就蹦出一大串
- 木箱和路灯是参考视频里“箱子与发光物体”新增的整合物体
- 机制参考：[把完整的物理引擎塞进2D沙盒里会怎样？](https://www.bilibili.com/video/BV1SeHi63EXV/)（仅文档引用，游戏本身不联网）

### 能力栏（9）

火焰、闪电、核弹、引力、冰霜、降雪、降雨、地震、风。

闪电会从屏幕顶端落到光标，并沿连通铁/铜导电、点燃附近木头；核弹与地震会制造刚体碎块和镜头震动。

### 地形栏（3）

修改地形（只在已有地形附近增补）、画笔（自由绘制）、矩形（拖框填充，带半透明绿色预览）。

### 两层物理

1. **体素材料层**：水、岩浆、雪、火、等离子、沙子、粉末和单个土 / 石 / 木 / 金属方块仍是格子模拟，逐格下落、蔓延和反应。
2. **整合刚体层**：木板、家具、木棍、木箱、路灯以及树木 / 爆炸 / 地震产生的碎块，以多个体素组成的物体在后台进行连续坐标的刚体模拟；每一帧再把物体姿态投影回低分辨率像素层，所以屏幕上看仍然是像素块，但它的运动会整体旋转、翻倒、堆叠，而不是散成一颗颗格子。

整合物体的可见结构保存在刚体内部，不会烘焙回地图格子；可以右键整体移除，被火焰烧到会逐渐燃烧消失，也可以被爆炸、引力、风推动。树根被烧断或炸掉、核弹/地震产生的碎块则会在一段时间后烘焙回地图，因此旧存档仍然按标准格子保存。

主要元素：空气、地面、石头、土、木头、铁、水、火、等离子、冰、泥、铜、雪、树叶、家具、树干、岩浆、沙子、火药。

## 五、设置与存档

设置项会立即写入 localStorage 键 `psb_config`：

- 音量 0–10
- 像素分辨率 3 / 4 / 5 / 6 px/格
- 画质 低 / 中 / 高（影响爆炸半径与震屏）
- 地图大小 小 / 中 / 大（宽高均为屏幕视口的 2.25 / 3.5 / 5.25 倍）

修改「像素分辨率」或「地图大小」会立即重置当前地图，页面和 toast 都会提示。地图宽高都会按倍率放大，所以 1280×720、5 px/格时：

- 小地图约为 576 × 324 格
- 中地图约为 896 × 504 格
- 大地图约为 1344 × 756 格

更改倍率后，之前用旧尺寸保存的地图会因尺寸不一致而无法读取，F9/导入时仍会给出提示。

存档：

- 地图键：`psb_save_1`，格式仍是 Base64( 宽 4 字节小端 + 高 4 字节小端 + 原始格子字节 )
- 整合物体键：`psb_props_1`，保存物体类型、位置、角度、速度、燃烧状态和内部体素颜色
- 读取和导入都会校验尺寸
- 导出 `.bin` 在原地图字节后追加 `PBJ1` 道具数据尾段；导入同时兼容旧版纯地图 `.bin` 和带整合物体的新版文件
- 顶栏和设置页都有「导出 .bin / 导入 .bin」按钮，方便跨浏览器、跨地址分享
- 所有 localStorage 读写都包在 try/catch 里；隐私模式或禁用存储时游戏仍可运行，只是不会持久化

> 存档与设置只保存在当前浏览器、当前源下。清浏览器数据会一并清除。  
> 旧版只含地图的存档在**尺寸一致**时可以直接读取；地图倍率改过之后，旧倍率生成的地图会提示尺寸不符。新版导出文件因整合物体数据而稍大一些。

## 六、实现说明

- 内置 `?selftest=1` 冒烟测试
- `window.onerror` / `unhandledrejection` 全局错误捕获，页面显示可复制的错误面板并输出控制台
- 60 FPS 的 requestAnimationFrame 渲染循环；模拟固定 30 Hz，时间累加器每帧最多补 2 步
- 世界使用离屏 canvas 低分辨率渲染后最近邻放大，`imageSmoothingEnabled = false`
- 整合物体的姿态在连续坐标中模拟，再写入 1 像素/格子的离屏刚体层，放大时保持像素边缘
- 所有音效由 WebAudio 程序化合成（Oscillator / BufferSource + Gain 包络 + BiquadFilter + 轻量压缩器），首次用户操作后 `resume()` 音频上下文
- 不使用撤销栈，刷新页面前请用 F5 或导出备份

## 七、已知限制

- 不是完整的刚体物理引擎：水、沙、火等仍是格子流体；整合物体用包围盒与地形/其他刚体碰撞，形状碰撞是近似值。
- 家具和木棍已经可以下落/翻滚；但不会模拟弯曲、绳索、铰链、活塞等连接结构。
- 整合物体暂不支持单独拾起或部分拆除；右键会移除整个对象。
- 没有撤销功能。
- 移动端保证基本可玩与横屏提示，但不保证所有手机的精细手感。
- 各种浏览器的 localStorage、全屏和方向锁定支持情况可能不同；不支持时会自动降级。
